# 基座模型评测总结

评测日期：2026-09-29～30。目的：了解蒸馏前的能力差距。本轮未训练模型，五个模型、七组设置（27B 含 low/medium/xhigh）× 四个 benchmark 均已完成，完整性检查通过。

## 1. 模型与设置

“基座”指未经本项目蒸馏的原始模型。三个本地模型均为 BF16：4B/9B 各用两个 H20 单卡实例；27B 每副本双卡：low/medium 用两个副本，xhigh 中途从两个扩到四个。Astra / Max 通过 API 调用。

| 模型 | 推理设置 | temperature | 其他显式采样设置 |
| --- | --- | --- | --- |
| Qwen3.5-4B / 9B | thinking=true；模板不支持 effort 档位 | 1.0 | top_p=0.95、top_k=20、presence_penalty=1.5 |
| Qwen3.8-27B | thinking=true；low / medium / xhigh | 0.6；EQ 0.7/0.5 | top_p=0.95 |
| GPT-6 Astra | API 请求 medium | 未传 | 未传 |
| Qwen3.8-Max | API 请求 medium | 0.6；EQ 0.7/0.5 | top_p=0.95 |

EQ 的 0.7/0.5 分别对应场景回答/debrief。未传的参数可能采用服务端默认值。27B 已补齐 low/medium/xhigh，复用原 medium；4B/9B 没有对应档位，不能称为“全部相同推理强度”。API 的 medium 也不能证明跨模型计算预算相同。

全部请求输出上限 32,768 token，仅用最终回答评分；长度耗尽仍计分。Max 曾返回超过该上限的结果，具体见下方核对结论。

## 2. Benchmark 简介

| Benchmark | 本轮规模 | 主要测什么 | 本轮计分方式 |
|---|---|---|---|
| IFEval | 541 题、834 条约束 | 是否遵守字数、格式、关键词等明确指令 | 官方程序检查；一题全部约束严格通过才算通过，报告题级通过率 |
| MultiChallenge | 273 题 | 多轮对话中的记忆、指令保持、版本修改和前后一致性 | 给定历史、生成末轮回答；裁判按官方条件判断，通过数 / 273 |
| EQ-Bench3 | 45 个有效场景，118 次模型调用（含追问） | 情绪理解、共情和复杂人际互动 | 按官方评分标准打分，维度均分映射到 0–100，再对场景取平均；不是 ELO |
| Arena-Hard-v2 | 750 题：500 难题 + 250 创作题 | 开放式复杂问题与创作回答质量 | 与固定参考答案比较，交换 A/B 顺序评分；强胜负权重 3、平局计半，报告加权胜率 |

Arena 难题参考答案来自 o3-mini-2025-01-31，创作题来自 Gemini 2.0 Flash。下面主表只展示 **500 道难题**，完整结果另含创作题。

## 3. 基座成绩

分数均为 0–100，越高越好。IFEval 使用官方程序检查，其余三项仅展示 **GPT-6 Astra 裁判**的评分。

| 模型 | IFEval | MultiChallenge | EQ-Bench3 | Arena 难题 |
|---|---:|---:|---:|---:|
| Qwen3.5-4B | 88.91 | 50.55 | 26.43 | 10.52 |
| Qwen3.5-9B | 90.76 | 55.31 | 30.80 | 12.64 |
| Qwen3.8-27B / low | 87.80 | 56.04 | 44.56 | 41.85 |
| Qwen3.8-27B / medium | 90.57 | 57.14 | 45.02 | 41.57 |
| Qwen3.8-27B / xhigh | 92.61 | 64.47 | 48.06 | 51.85 |
| GPT-6 Astra | 95.93 | 72.53 | 82.78 | 98.91 |
| Qwen3.8-Max | 94.27 | 68.50 | 67.33 | 92.56 |

**初步判断：**27B 的 xhigh 四项分数均高于 medium：MultiChallenge / Arena 分别提高 7.33 / 10.28 分，CoT 总量增至约 5.15 倍。是否能把教师差距转化为蒸馏收益，仍需训练验证。

**解释边界：**Qwen3.5 与 Qwen3.8 的代际和采样设置不同，不能把差异单独归因于参数规模。Astra 参与自身评分，可能存在自评偏差，不能仅据此确定模型的绝对排名。本轮不是 SSR 论文数值的精确复现，也不是官方排行榜成绩；Arena 未做风格控制。

## 5. 输出与 CoT token 消耗

统计五个模型、七组设置的最终保留结果。单元格格式：**输出 token（CoT token）**，输出包含推理和最终答案。四个 benchmark 列为平均每题用量；末列为四项合计。**这里 Arena 含 500 道难题＋250 道创作题，与成绩表的难题子集不同。**

| 模型 | IFEval | MultiChallenge | EQ-Bench3 | Arena 全部750题 | 总 token |
| --- | ---: | ---: | ---: | ---: | ---: |
| Qwen3.5-4B* | 4,977（4,647） | 4,751（4,138） | 8,442（6,028） | 6,197（4,772） | 9,017,495（7,494,242） |
| Qwen3.5-9B* | 4,375（4,102） | 4,213（3,565） | 8,771（6,241） | 6,214（4,671） | 8,572,277（6,976,244） |
| Qwen3.8-27B / low* | 1,180（772） | 1,314（737） | 6,221（2,611） | 3,780（2,047） | 4,112,057（2,271,329） |
| Qwen3.8-27B / medium* | 1,406（967） | 1,689（937） | 8,448（3,789） | 4,033（2,197） | 4,627,108（2,597,681） |
| Qwen3.8-27B / xhigh* | 1,910（1,645） | 3,787（2,706） | 52,836（50,133） | 14,033（12,662） | 14,968,850（13,381,452） |
| GPT-6 Astra | 453（105） | 615（75） | 3,342（237） | 1,461（278） | 1,659,464（296,030） |
| Qwen3.8-Max | 1,610（1,297） | 3,819（2,605） | 14,400（11,115） | 11,999（9,749） | 11,560,505（9,225,059） |

**七组设置合计约 54.52M 输出 token，其中 CoT 约 42.24M。**

- 每组设置题数：541 / 273 / 45 / 750。EQ 的 45 个场景包含多轮及 debrief，共 118 次生成；表中按完整场景平均，因此 EQ 的均值可超过单次调用的 32K 上限。
- 输出总量采用接口 usage；带 * 的本地模型 CoT 用各自分词器复算，属于估算；Astra / Max 的 CoT 使用 API 返回的 reasoning_tokens。不同分词器和接口统计口径不完全可比，Astra 的计数也不代表可获得完整 CoT 文本。
- 仅统计被测模型最终保留的生成（含达到长度上限的样本）；不含输入、裁判、失败重试及废弃运行，不能当作全部运行账单。

[原五组明细](../training_data/analysis/cot_token_usage.json) · [核对记录](analysis/token_usage_audit.json)

### 原五组结果的统计口径核对（27B 指 medium）

- **不是同一推理设置。** 4B/9B 只有 thinking 开关；27B 模板支持并使用 medium（该档不额外追加强度指令），Astra/Max 是 API 请求 medium。温度等采样设置也不同，长度差异不能单独归因于模型大小或 effort。
- **计数复核通过。** 五模型题目 ID/输入哈希一致；原 token 汇总全部复算一致。将四个 Qwen 的可见 CoT 统一用 27B 分词器计数，三个本地模型总量不变，Max 仅比接口统计少 78 token（922 万中），因此大幅长度差异并非分词器造成。Astra 没有完整 CoT 文本，无法同法复核。
- **预算上限未严格对齐。** Max 有 55/1,682 次输出超过 32,768 token（IFEval 1、MultiChallenge 2、Arena 52），最大 140,699；其他四模型均未超限。Max 的长尾会抬高均值。
- **Max 并非各项都更短。** 相比 9B，Max 在 IFEval/MultiChallenge 的 CoT 较短，在 EQ/Arena 更长；27B 则四项都较短。现有数据只能说明本轮设置下的长度，若要比较等预算效率，需另做统一采样与实际输出上限的对照。

**27B 强度对照：** low / medium / xhigh 使用同一权重、题目、采样参数、32K 输出上限与 Astra 裁判；执行和重试差异另行注明。medium 沿用此前结果，新两档各只保留一份完整结果。各档仅运行一次，小幅分差不代表显著提升。[分档成绩、token 与耗时明细](analysis/qwen38_effort_summary.json)。

xhigh 的 MultiChallenge 有 1 题用尽六次重试后补跑；最终返回 32K 截断空答，已原样计分。

32K 截断调用数（每档 1,682 次生成）：low 6、medium 4、xhigh 180；新两档保留记录中带重试的调用数为 6 / 24。沿用原脚本：正常终止却无最终答案时重试；截断样本保留计分。token 表仅计保留结果，不含重试开销。
