# 研究阶段与核心结论

模型为 Qwen3.5-9B。新训练使用4,175条配对样本、LoRA rank16、LR1e-5、1epoch、8K上限，每组131步。screen100用于开发搜索；confirm200为一次确认；四benchmark终评与开发反馈分开记录。

| 阶段 | 做了什么 | 结论与材料位置 |
|---|---|---|
| 基础格式 | 空CoT、普通段落、分步标签 | 开发分数49.0、46.5、41.5，未通过原初筛门槛；results/development/ |
| 答案NLL选择 | 逐题选格式，与匹配随机比较 | 41.0 vs 49.0，未通过；训练数据在data/train/ |
| 正文NLL选择 | 按共同正文NLL选格式，与长度/类别配额匹配随机比较 | 48.0 vs 44.0；差值+4，95%区间[-5,+13]，优势未确定 |
| 独立确认 | 固定confirm200，正文选择对基座 | 53.25，区间[48.00,58.25]；results/confirmation/ |
| 同LR方法对照 | NEU、SUP、AUG-SUP、SSR与正文选择 | 45.0、45.0、46.5、50.5、48.0，尚未证明正文选择超过四方法 |
| 四benchmark终评 | 正文选择、SUP、AUG-SUP、SSR | 仅7/16完整评分；results/benchmarks/明确保留缺失项 |
| 运行收尾 | 停止后保留成功/失败原始请求及巡检记录 | 20个分类归档；未补题、未刷新终评结果 |

## 对照设计

正文选择与匹配随机保持Q/A逐字固定，plain/steps配额同为2128/2047，2018条实际CoT不同，CoT总长度差0.0301%。确认集输出token减少49.93%、估计CoT减少59.54%；这些变化不能证明同等质量或解释因果关系。

## 终评缺口

正文选择、SUP各前三项完成评分，AUG-SUP仅IFEval完成评分。首波Arena缺3题；AUG-SUP MultiChallenge为272/273。SSR IFEval为537/541，其余4题有正常stop但final为空的返回；其他三个benchmark尚未生成。缓存归档保留原始返回和失败记录。

## 解释边界

screen被多轮使用，配对区间没有覆盖训练、生成、裁判方差及适应性搜索偏差。确认集只有正文选择与基座，没有同轮NEU或随机确认对照。终评不完整，不作最终排名。
